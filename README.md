## 🧩 Overview

**Guess-the-Number** is a simple interactive console game written in Python. The program randomly selects a number, and the player must guess it within a certain number of tries or within hints. It’s a great beginner project to practice basic programming concepts like loops, conditionals, user input, and validation.

---

## ✨ Features

- Random number generation (within a defined range)  
- User input and validation  
- Feedback on guesses (too low / too high)  
- Counting number of attempts  
- Replay option to start a new game
